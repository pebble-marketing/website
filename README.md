# pebblemarketing.ai

Static "coming soon" page for Pebble Marketing, served by GitHub Pages on the apex domain `pebblemarketing.ai`.

- `index.html` — the whole site, self-contained (inline CSS, inline SVG).
- `assets/mark.png` — Pebble mark, vendored locally (do not re-point at a Workers URL).
- `CNAME` — created automatically by Settings → Pages when the custom domain is set. Do not hand-edit.
- `.nojekyll` — skip Jekyll processing.

This repo is public because GitHub Pages requires it on the free plan. It must contain
nothing but the public site — no strategy artifacts, no engagement material.
